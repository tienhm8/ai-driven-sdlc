# documentation

## How to proceed

1. Read the task, stack, conventions, and approved scope before starting.
2. Pick the audience and the task they need to do; keep the source of commands, versions, and decisions.
3. Run safe commands or mark them unverified; check paths and examples.

## Handover

Report the decision, the evidence checked, and anything not verified; pass items that need approval to the responsible person.
