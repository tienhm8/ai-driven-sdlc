# Knowledge: security

Lập danh mục tài sản và trust boundaries; đặt quyền tối thiểu, kiểm tra quyền theo tài nguyên, lọc dữ liệu nhạy cảm khỏi log. Bằng chứng review phải được che dữ liệu; ưu tiên biện pháp giảm thiểu và kiểm thử phòng thủ.

Ghi các quyết định và giá trị đo thực tế tại tài liệu của dự án, không đưa cấu hình hoặc dữ liệu đặc thù vào thư viện chung.
