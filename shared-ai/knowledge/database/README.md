# Knowledge: database

Chọn mô hình dựa trên bất biến dữ liệu và truy vấn thực tế. Review transaction, khóa, chỉ mục và retention. Thử backup/restore trên bản dữ liệu không nhạy cảm; ghi RPO, RTO và thời gian phục hồi đo được.

Ghi các quyết định và giá trị đo thực tế tại tài liệu của dự án, không đưa cấu hình hoặc dữ liệu đặc thù vào thư viện chung.
