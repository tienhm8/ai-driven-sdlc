# Tích hợp github-copilot

Đích tham khảo: `.github/copilot-instructions.md` trong code repo. Xác nhận quy ước theo phiên bản client đang dùng. Đây là hướng dẫn tích hợp, không phải cấu hình tự kích hoạt.

Thực hiện bốn bước trong [quy trình chung](../generic/README.md).

- **Đường dẫn và phạm vi:** một file `.github/copilot-instructions.md` áp dụng cho toàn code repo.
- **Kiểm tra riêng:** mở phiên thử, yêu cầu Copilot nêu rule đang áp dụng và đọc một skill.
