# Tích hợp claude-code

Đích tham khảo: `CLAUDE.md`; skill đã chọn dưới `.claude/skills/<id>/SKILL.md`. Xác nhận quy ước theo phiên bản client đang dùng. Đây là hướng dẫn tích hợp, không phải cấu hình tự kích hoạt.

Thực hiện bốn bước trong [quy trình chung](../generic/README.md).

- **Đường dẫn và phạm vi:** đặt `CLAUDE.md` và các skill đã chọn trong code repo đích.
- **Kiểm tra riêng:** trong phiên thử, yêu cầu Claude Code nêu rule đang áp dụng và đọc một skill dưới `.claude/skills/`.
