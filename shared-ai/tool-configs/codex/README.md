# Tích hợp codex

Đích tham khảo: `AGENTS.md` ở repo hoặc thư mục cần áp dụng. Xác nhận quy ước theo phiên bản client đang dùng. Đây là hướng dẫn tích hợp, không phải cấu hình tự kích hoạt.

Thực hiện bốn bước trong [quy trình chung](../generic/README.md).

- **Đường dẫn và phạm vi:** đặt `AGENTS.md` ở gốc repo hoặc thư mục con; hướng dẫn chỉ áp dụng cho phạm vi thư mục chứa nó.
- **Kiểm tra riêng:** trong phiên thử ở đúng thư mục, yêu cầu Codex nêu rule đang áp dụng và đọc một skill.
