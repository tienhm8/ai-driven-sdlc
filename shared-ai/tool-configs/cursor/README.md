# Tích hợp cursor

Đích tham khảo: `.cursor/rules/*.mdc` theo phạm vi repo. Xác nhận quy ước theo phiên bản client đang dùng. Đây là hướng dẫn tích hợp, không phải cấu hình tự kích hoạt.

Thực hiện bốn bước trong [quy trình chung](../generic/README.md).

- **Đường dẫn và phạm vi:** mỗi rule `.mdc` nằm trong `.cursor/rules/` của repo; giữ mỗi file theo một phạm vi áp dụng.
- **Kiểm tra riêng:** mở phiên thử, kiểm tra rule `.mdc` đã được nạp cho file đang làm việc và đọc được một skill.
