# Checklist tính đầy đủ của đầu vào (Input Completeness Checklist)

| Mã | Mục kiểm tra | Trạng thái | Ghi chú |
|---|---|---|---|
| IC-01 | Mục tiêu nghiệp vụ đã được cung cấp | | |
| IC-02 | Vấn đề nghiệp vụ đã được xác định | | |
| IC-03 | Phạm vi dự án đã được định nghĩa | | |
| IC-04 | Các hạng mục trong phạm vi đã được xác định | | |
| IC-05 | Các hạng mục ngoài phạm vi đã được xác định | | |
| IC-06 | Các bên liên quan chính đã được xác định | | |
| IC-07 | Người dùng mục tiêu đã được xác định | | |
| IC-08 | Quy trình nghiệp vụ đã được tài liệu hóa | | |
| IC-09 | Thông tin hệ thống hiện có đã có sẵn hoặc được đánh dấu N/A | | |
| IC-10 | Ràng buộc kỹ thuật đã được xác định | | |
| IC-11 | Ràng buộc nghiệp vụ đã được xác định | | |
| IC-12 | Phiên bản tài liệu đầu vào đã được ghi nhận | | |

## Tiêu chí hoàn thành

- Tất cả mục bắt buộc PHẢI đạt (PASS).
- Mục N/A PHẢI có lý do hợp lệ.
- Thông tin còn thiếu PHẢI được ghi nhận.
- Thông tin còn thiếu quan trọng PHẢI được làm rõ trước khi phê duyệt yêu cầu cuối cùng.
