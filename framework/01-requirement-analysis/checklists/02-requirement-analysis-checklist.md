# Checklist phân tích yêu cầu (Requirement Analysis Checklist)

| Mã | Mục kiểm tra | Trạng thái | Ghi chú |
|---|---|---|---|
| RA-01 | Mục tiêu nghiệp vụ đã được phân tích | | |
| RA-02 | Phạm vi nghiệp vụ đã được phân tích | | |
| RA-03 | Nhu cầu của các bên liên quan đã được xác định | | |
| RA-04 | Yêu cầu chức năng đã được xác định | | |
| RA-05 | Yêu cầu phi chức năng đã được xác định | | |
| RA-06 | Quy tắc nghiệp vụ đã được xác định | | |
| RA-07 | Vai trò người dùng đã được xác định | | |
| RA-08 | Các luồng nghiệp vụ chính đã được xác định | | |
| RA-09 | Các tích hợp bên ngoài đã được xác định | | |
| RA-10 | Yêu cầu về dữ liệu đã được xác định | | |
| RA-11 | Các kịch bản ngoại lệ đã được xem xét | | |
| RA-12 | Các phụ thuộc đã được xác định | | |
| RA-13 | Các nội dung loại trừ khỏi phạm vi đã được tài liệu hóa | | |

## Tiêu chí hoàn thành

Mọi yêu cầu nghiệp vụ liên quan PHẢI được xác định và tài liệu hóa, kèm tham chiếu đến nguồn.
