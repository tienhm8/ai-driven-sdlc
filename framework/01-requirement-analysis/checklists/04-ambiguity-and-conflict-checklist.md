# Checklist mơ hồ và mâu thuẫn (Ambiguity and Conflict Checklist)

| Mã | Mục kiểm tra | Trạng thái | Ghi chú |
|---|---|---|---|
| AMB-01 | Thuật ngữ mơ hồ đã được nhận diện | | |
| AMB-02 | Thuật ngữ nghiệp vụ chưa được định nghĩa đã được ghi nhận | | |
| AMB-03 | Yêu cầu mâu thuẫn đã được nhận diện | | |
| AMB-04 | Quy tắc nghiệp vụ còn thiếu đã được nhận diện | | |
| AMB-05 | Quyền người dùng chưa rõ ràng đã được nhận diện | | |
| AMB-06 | Chuyển đổi luồng nghiệp vụ chưa rõ ràng đã được nhận diện | | |
| AMB-07 | Kịch bản ngoại lệ còn thiếu đã được nhận diện | | |
| AMB-08 | Giả định chưa được xác minh đã được nhận diện | | |
| AMB-09 | Câu hỏi còn mở đã được tài liệu hóa | | |
| AMB-10 | Mỗi vấn đề có người phụ trách hoặc hướng xử lý | | |

## Tiêu chí hoàn thành

Không có mơ hồ hoặc mâu thuẫn quan trọng nào chưa được giải quyết được phép coi là yêu cầu đã phê duyệt.

Mọi vấn đề chưa được giải quyết PHẢI được ghi nhận trong `outputs/10-assumptions-constraints-risks/open-questions.md`.
