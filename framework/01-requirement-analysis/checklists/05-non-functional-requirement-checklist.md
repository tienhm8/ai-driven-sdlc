# Checklist yêu cầu phi chức năng (Non-Functional Requirement Checklist)

| Mã | Hạng mục | Tiêu chí kiểm tra | Trạng thái |
|---|---|---|---|
| NFR-01 | Hiệu năng (Performance) | Thời gian phản hồi và thông lượng | |
| NFR-02 | Khả năng mở rộng (Scalability) | Mức tăng trưởng và khối lượng công việc dự kiến | |
| NFR-03 | Tính sẵn sàng (Availability) | Mục tiêu sẵn sàng | |
| NFR-04 | Độ tin cậy (Reliability) | Khả năng phục hồi và chịu lỗi | |
| NFR-05 | Bảo mật (Security) | Xác thực và phân quyền | |
| NFR-06 | Quyền riêng tư (Privacy) | Bảo vệ dữ liệu cá nhân | |
| NFR-07 | Khả năng sử dụng (Usability) | Yêu cầu về trải nghiệm người dùng | |
| NFR-08 | Khả năng tương thích (Compatibility) | Trình duyệt, thiết bị và nền tảng | |
| NFR-09 | Khả năng bảo trì (Maintainability) | Kỳ vọng về bảo trì | |
| NFR-10 | Khả năng quan sát (Observability) | Ghi log, metrics và tracing | |
| NFR-11 | Sao lưu và khôi phục (Backup & Recovery) | Mục tiêu sao lưu và khôi phục | |
| NFR-12 | Tuân thủ (Compliance) | Yêu cầu pháp lý và quy định | |

## Tiêu chí hoàn thành

Các NFR áp dụng PHẢI được tài liệu hóa kèm tiêu chí đo (chỉ số, ngưỡng, điều kiện đo khi cần) hoặc phương pháp kiểm chứng với kết quả đạt/không đạt rõ ràng.

KHÔNG tự đặt ra các con số mục tiêu. Khi chưa có mục tiêu, PHẢI yêu cầu bên liên quan làm rõ.
