# Checklist chất lượng yêu cầu (Requirement Quality Checklist)

| Mã | Thuộc tính chất lượng | Tiêu chí kiểm tra | Trạng thái |
|---|---|---|---|
| RQ-01 | Rõ ràng (Clear) | Yêu cầu dễ hiểu | |
| RQ-02 | Đầy đủ (Complete) | Bao gồm thông tin cần thiết | |
| RQ-03 | Nhất quán (Consistent) | Không mâu thuẫn với các yêu cầu khác | |
| RQ-04 | Kiểm thử được (Testable) | Có thể xác minh thông qua kiểm thử | |
| RQ-05 | Khả thi (Feasible) | Khả thi về kỹ thuật và vận hành | |
| RQ-06 | Cần thiết (Necessary) | Hỗ trợ mục tiêu nghiệp vụ | |
| RQ-07 | Truy vết được (Traceable) | Có nguồn gốc và mã ID duy nhất | |
| RQ-08 | Nguyên tử (Atomic) | Mô tả đúng một yêu cầu | |
| RQ-09 | Có độ ưu tiên (Prioritized) | Có độ ưu tiên nghiệp vụ | |
| RQ-10 | Không mơ hồ (Unambiguous) | Chỉ có một cách hiểu hợp lý | |

## Tiêu chí hoàn thành

Các yêu cầu quan trọng PHẢI đạt tất cả kiểm tra chất lượng áp dụng được trước khi phê duyệt G1.
