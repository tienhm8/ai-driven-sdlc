# User Story

Dùng [mẫu User Story chuẩn của Stage 01](../../01-requirement-analysis/templates/user-story.md). Trong dự án đã khởi tạo, mẫu làm việc nằm tại `docs/01-requirement-analysis/_templates/user-story.md`.

File này chỉ dẫn tới mẫu chuẩn, không dùng để điền. Story giữ ID và tóm tắt tiêu chí nghiệm thu; điều kiện nghiệm thu đầy đủ nằm trong hồ sơ Acceptance Criteria.
