# Tiêu chuẩn lập trình (Coding Standards)

## 1. Mục đích

Thư mục này định nghĩa các tiêu chuẩn chung cho việc triển khai phần mềm và đảm bảo chất lượng.

## 2. Tài liệu

| Tài liệu | Phạm vi |
|---|---|
| `coding-standards.md` | Chất lượng, cấu trúc, khả năng đọc và khả năng bảo trì của mã nguồn |
| `testing-standards.md` | Chiến lược kiểm thử, thiết kế test, thực thi và tiêu chí chất lượng |

## 3. Phạm vi áp dụng

Các tiêu chuẩn này áp dụng cho:

- Mã nguồn ứng dụng.
- Các bài kiểm thử tự động.
- Script và automation.
- Mã hạ tầng (infrastructure code).
- Mã do AI tạo ra hoặc chỉnh sửa.
- Code review và đảm bảo chất lượng.

## 4. Quy tắc riêng theo công nghệ

Tiêu chuẩn chung định nghĩa các yêu cầu không phụ thuộc vào công nghệ.

Dự án NÊN duy trì hướng dẫn lập trình riêng theo công nghệ cho ngôn ngữ, framework và công cụ mà dự án sử dụng.

Ví dụ:

- Hướng dẫn lập trình Java.
- Hướng dẫn lập trình TypeScript.
- Hướng dẫn lập trình Python.
- Hướng dẫn phát triển React.
- Hướng dẫn phát triển Spring Boot.

Hướng dẫn riêng theo công nghệ PHẢI nhất quán với tiêu chuẩn chung.
