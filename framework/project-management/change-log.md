## Workflow
`Proposed → Under Assessment → Pending Approval → Approved / Rejected / Deferred → Implemented → Verified`

Tạo request bằng `templates/change-request-template.md`; đánh giá impact; xin đúng thẩm quyền; chỉ cập nhật baseline sau approval; liên kết `DEC-*` và `APR-*`. Giữ lại request bị từ chối/hoãn để audit.
