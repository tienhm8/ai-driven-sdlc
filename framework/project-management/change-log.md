## Workflow
`Proposed → Under Assessment → Pending Approval → Approved / Rejected / Deferred → Implemented → Verified`

Cấp ID dạng `CHG-0001` theo [ID Conventions](README.md#nguồn-chuẩn). Dùng [mẫu change request](README.md#mẫu-hồ-sơ); đánh giá impact; xin đúng thẩm quyền; chỉ cập nhật baseline sau approval; liên kết `DEC-*` và `APR-*`. Giữ lại request bị từ chối/hoãn để audit.
