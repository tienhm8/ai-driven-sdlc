# Checklist Rà soát Dependency
- [ ] Mỗi dependency có ID, predecessor và successor.
- [ ] Đã phân loại Type và trạng thái blocking.
- [ ] Đã xác nhận owner/liên hệ bên ngoài và lead time.
- [ ] Ngày Required-by thực tế.
- [ ] Đã xác định và xử lý dependency vòng tròn.
- [ ] Thứ tự khớp với thiết kế architecture/API/data.
- [ ] Đã xác định critical path và công việc song song.
- [ ] Dependency tác động lớn có biện pháp giảm thiểu/dự phòng.
- [ ] Các dependency về phê duyệt/gate đã được đưa vào lịch.
Kết quả: `[Accepted/Changes Requested]`; Tech Lead/ngày/dependency còn mở.
