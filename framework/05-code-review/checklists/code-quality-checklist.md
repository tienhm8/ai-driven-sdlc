# Code Quality Checklist

- [ ] Thay đổi đúng scope và đáp ứng Acceptance Criteria.
- [ ] Luồng nghiệp vụ, điều kiện và trạng thái nhất quán.
- [ ] Không có nhánh dead code hoặc logic trùng lặp đáng kể.
- [ ] Error handling không nuốt lỗi hoặc làm mất ngữ cảnh.
- [ ] Naming, readability và cấu trúc phù hợp coding standards.
- [ ] Không tạo coupling hoặc abstraction không cần thiết.
- [ ] Log/metric đủ hỗ trợ vận hành nhưng không lộ dữ liệu nhạy cảm.
- [ ] Có test cho logic mới và regression quan trọng.
- [ ] Tài liệu được cập nhật khi behavior/API thay đổi.
