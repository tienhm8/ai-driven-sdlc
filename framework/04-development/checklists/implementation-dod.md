# Development Definition of Done

- [ ] Code đáp ứng các Acceptance Criteria liên quan.
- [ ] Thay đổi nằm trong phạm vi task đã duyệt.
- [ ] Tuân thủ kiến trúc và coding guidelines.
- [ ] Validation, error handling và logging phù hợp.
- [ ] Không có secret hard-code/commit hoặc dữ liệu nhạy cảm trái phép.
- [ ] Đã review authorization và truy cập dữ liệu.
- [ ] Đã thêm/cập nhật các test liên quan.
- [ ] Đã chạy build, lint/format, type check, test, static analysis và security check bắt buộc; ghi lệnh, SHA và kết quả thực tế vào test evidence. Tiêu chí đạt hoặc ngoại lệ cho các check bắt buộc khi bàn giao được quy định tại [PR Readiness Check](../workflow.md#410-pr-readiness-check--bàn-giao-04--05).
- [ ] Không tắt kiểm soát test hoặc bảo mật để ép pass.
- [ ] Đã ghi tác động lên API/schema/migration/config/tương thích.
- [ ] Đã cập nhật tài liệu kỹ thuật khi behavior, interface hoặc vận hành thay đổi.
- [ ] Developer đã review toàn bộ diff.
- [ ] Đã ghi known issue, khoảng trống test và rủi ro còn lại.
- [ ] Đã kiểm tra các tiêu chí DoD riêng của task (nếu có).
